## 🎨 Theme & Design Guidelines (CRITICAL)

Seluruh halaman dan komponen baru **WAJIB** mengikuti aturan tema ini agar tidak melenceng dari identitas visual aplikasi.

### 1. Warna Semantik (Semantic Colors)
Jangan pernah menggunakan warna hardcoded (misal: `text-blue-500`). Gunakan variabel tema:
- **Primary**: Warna utama aplikasi (Sky/Blue). Gunakan class `bg-primary`, `text-primary`, atau spesifik `primary-600` (light) / `primary-500` (dark).
- **Secondary**: Warna pendukung (Teal). Gunakan class `secondary-600`.
- **Accent**: Warna aksen (Purple/Indigo). Gunakan class `accent-500`.
- **Muted**: Untuk latar belakang halus atau teks kurang penting. Gunakan `slate-100` (light) / `slate-800` (dark).
- **Surface**: Latar belakang komponen. Gunakan `bg-white` (light) / `bg-slate-900` (dark).

### 2. Sudut Melengkung (Border Radius)
- **Input, Tombol, Tab, Tag**: Gunakan `rounded-xl` (12px).
- **Card, Modal, Popover, Sheet**: Gunakan `rounded-2xl` (16px).
- **Avatar, Badge, Checkbox/Radio**: Gunakan `rounded-full`.

### 3. Efek Kedalaman (Shadows & Borders)
- **Border Default**: `border-slate-200` (light) / `border-slate-800` (dark).
- **Shadow Default**: `shadow-sm` untuk elemen kecil.
- **Shadow Premium**: `shadow-xl` atau `shadow-2xl` untuk Modal dan Popover agar terlihat mewah.
- **Dashed Border**: Gunakan `border-dashed border-slate-300` untuk area upload atau contoh di dokumentasi.

### 4. Tipografi
- **Heading**: Gunakan `font-bold` atau `font-extrabold` dengan tracking rapat `tracking-tight`.
- **Labels**: Gunakan `text-xs font-semibold uppercase tracking-wider text-slate-400` untuk sub-heading kecil.

## 🏗️ Project Structure (TanStack Router)

```
src/
├── routes/                       # TanStack Router (File-based)
│   ├── (admin)/                  # Admin group (Protected)
│   ├── (auth)/                   # Auth group (Login/Register)
│   ├── (public)/                 # Public pages
│   │   └── docs/                 # Documentation (split by category)
│   ├── docs.tsx                  # Docs layout (with sidebar)
│   └── __root.tsx                # Root layout & providers
│
├── components/                   # UI Components
│   └── ui/                       # Reusable UI Atoms
│       ├── form/                 # Input, Select, Switch, etc.
│       ├── feedback/             # Alert, Toast, Loading, etc.
│       ├── overlay/              # Button, Dialog, Popover, etc.
│       ├── navigation/           # Sidebar, Breadcrumb, Tabs, etc.
│       └── data/                 # Table, Stat, Timeline, etc.
│
├── store/                        # Zustand stores (themeStore, authStore)
├── styles/                       # globals.css (Theme source of truth)
└── routeTree.gen.ts              # Generated by TanStack Router
```

## 🔄 Theme System Implementation

1. **globals.css**: Sumber utama definisi warna. Menggunakan CSS Variables (`--color-primary-600`, dll) dalam blok `:root`.
2. **Generic Mappings**: Class seperti `bg-primary` sudah dipetakan ke variabel tema. Selalu prioritaskan class semantik ini.
3. **Dark Mode**: Gunakan prefix `dark:` secara konsisten. Contoh: `bg-white dark:bg-slate-900`.
4. **Programmatic Access**: Gunakan hook `useTheme()` dari `@/store/themeStore` jika perlu mengecek state tema di dalam JavaScript.

## ✅ Best Practices
- **Consistency**: Lihat komponen yang sudah ada di `/docs` sebelum membuat yang baru.
- **Layouts**: Gunakan `Sidebar` dan `Navbar` yang sudah tersedia untuk halaman internal.
- **Forms**: Gunakan `react-hook-form` + `zod` untuk validasi.
- **SPA Feel**: Selalu gunakan komponen `Link` dari `@tanstack/react-router` untuk navigasi internal agar cepat.
