## 🎨 Frontend Standards

### Architecture
- **Pattern:** Feature-based module structure
- **Location:** `/golang-next/frontend/src/features/[feature]/`
- **Each feature contains:** `schemas/`, `services/`, `store/`, `hooks/`, `types/`, `index.ts`

### Key Technologies
- **Framework:** Next.js 16 with App Router
- **Language:** TypeScript (strict mode)
- **Styling:** Tailwind CSS v4 with CSS Variables
- **State:** Zustand (auth store in features/auth/)
- **Forms:** React Hook Form + Zod
- **API Client:** Native Fetch (NO AXIOS)
- **UI Components:** 50+ Radix-based components

### File Organization
```
src/
├── app/                   # Next.js pages & layouts
├── features/              # Feature modules (REQUIRED)
│   └── [feature]/
│       ├── schemas/       # Zod schemas
│       ├── services/      # API calls
│       ├── store/         # Zustand stores
│       ├── hooks/         # Custom hooks
│       ├── types/         # TypeScript types
│       └── index.ts       # Exports
├── components/ui/         # Shared components
├── lib/                   # Utilities
├── store/                 # Global stores (theme, etc)
├── hooks/                 # Global hooks
├── providers/             # React providers
└── styles/                # Global CSS

AVOID:
❌ Flat file structure (hooks/, stores/ at root)
❌ File-type organization (all components together)
```

### Code Patterns

**Component Import:**
```tsx
// ✅ CORRECT
import { Button } from "@/components/ui/overlay/button";
import { useAuthStore } from "@/features/auth/store/authStore";
import { loginSchema } from "@/features/auth/schemas/login";

// ❌ WRONG
import { Button } from "../../../components/ui/button";
```

**Form Handling:**
```tsx
// Use Zod + React Hook Form ALWAYS
const schema = z.object({
  email: z.string().email(),
  password: z.string().min(6),
});

const { register, handleSubmit, formState: { errors } } = useForm({
  resolver: zodResolver(schema),
  mode: "onBlur",
  defaultValues: { /* ... */ }
});
```

**API Calls:**
```tsx
// Use fetch-based service (no axios)
export const authService = {
  async login(credentials: LoginFormData) {
    const response = await fetch(`${API_URL}/api/auth/login`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(credentials),
    });
    return { ok: response.ok, data: await response.json() };
  }
};
```

### Code Patterns

**Handler Pattern:**
```go
// internal/handlers/auth.go
type AuthHandler struct {
  authService *services.AuthService
}

func (h *AuthHandler) Login(c *gin.Context) {
  var req models.LoginRequest
  if err := c.ShouldBindJSON(&req); err != nil {
    c.JSON(400, models.ErrorResponse{Success: false})
    return
  }
  
  loginResp, err := h.authService.Login(c.Request.Context(), req.Email, req.Password)
  if err != nil {
    c.JSON(401, models.ErrorResponse{Error: err.Error()})
    return
  }
  
  c.JSON(200, models.SuccessResponse{Data: loginResp})
}
```

**Service Pattern:**
```go
// internal/services/auth_service.go
type AuthService struct {
  userRepo *repositories.UserRepository
}

func (s *AuthService) Login(ctx context.Context, email, password string) (*models.LoginResponse, error) {
  user, err := s.userRepo.FindByEmail(ctx, email)
  if err != nil {
    return nil, errors.New("user not found")
  }
  
  if !utils.VerifyPassword(user.Password, password) {
    return nil, errors.New("invalid password")
  }
  
  token, _ := utils.GenerateJWT(user.ID.Hex())
  return &models.LoginResponse{User: user, Token: token}, nil
}
```

- ✅ **Logging:** Use structured logging
- ✅ **Testing:** Unit + integration tests
- ✅ **Comments:** Explain why, not what
- ✅ **Naming:** Clear, concise variable names

## 🔄 Development Workflow

### For Each Feature Implementation:

1. **Read Documentation**
   - Read relevant CODE_GUIDE.md and ARCHITECTURE.md
   - Check plan.md for requirements
   - Look at similar existing code

2. **Create Feature Module**
   - Create folder: `src/features/[feature]/`
   - Create subfolders: `schemas/`, `services/`, `store/`, `hooks/`, `types/`
   - Create `index.ts` with barrel exports

3. **Implement in Order**
   - Schemas (Zod)
   - Services (API client)
   - Store (Zustand if needed)
   - Components
   - Page/handler

4. **Test**
   - Build: `npm run build` (frontend) or `go build` (backend)
   - Check: `npm run type-check` (frontend)
   - Run: `npm run dev` or `go run ./cmd/main.go`
   - Verify: No errors, works as expected

5. **Update Tracking**
   - Mark todo as `done` in SQL
   - Update plan.md if phase completes
   - Commit with message: "feat: [feature description]"

## 🆘 Troubleshooting

### Frontend Build Fails
1. Check error message carefully
2. Run `npm install` to ensure dependencies
3. Check tsconfig.json for path aliases
4. Verify imports use @/ prefix
5. Check CLAUDE.md for patterns

### Backend Build Fails
1. Check go.mod for missing packages
2. Run `go mod tidy` to clean dependencies
3. Verify context usage in functions
4. Check for missing error handling
5. Review CLAUDE.md for patterns

### TypeScript Errors
1. Don't use `any` - be explicit
2. Use `z.infer<typeof schema>` for zod types
3. Add `type` keyword for type-only imports
4. Check strict mode is enabled
5. Reference CLAUDE.md examples
